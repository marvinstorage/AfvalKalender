## Why

Issue #30: the apps use platform placeholders (the Avalonia icon on Desktop, the default MAUI icon on Android). A recognisable logo makes the app easy to find on a phone, in the taskbar and in the start menu.

## What Changes

- The supplied logo (`assets/logo-source.jpg`: waste bins, calendar, bell and the Twente horse) is the single source; `scripts/make-logo-icons.py` derives the other files from it.
- Android: the logo is the app icon, generated by .NET MAUI from `assets/logo-foreground.png` (`MauiIcon`, transparent artwork on a white adaptive background).
- Desktop: `Assets/app-logo.ico` (generated from the logo) replaces the Avalonia placeholder for the window and taskbar icon; the .deb start-menu entry uses the same icon.
- README shows the logo.
- Console: a terminal cannot show an icon; no change.

## Capabilities

### Modified Capabilities
- `platform-android`: the packaged app has the AfvalKalender app icon.
- `ui-desktop`: the window uses the AfvalKalender icon.

## Impact

- Presentation only (AndroidUI csproj, DesktopUI window and csproj, `.deb` packaging script, README, assets). No Domain, Application or Infrastructure change, no new NuGet package.
- The Android build is not part of normal CI; it is verified with the `release.yml` dry run and the emulator.
